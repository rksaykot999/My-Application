## ❌ IF NOTIFICATIONS DON'T APPEAR

**Check in order:**

1. **Permission granted?**
   ```
   Settings → Apps → YourApp → Permissions → Notifications → ON
   ```

2. **App built successfully?**
   ```
   Build → Make Project
   Should say: "BUILD SUCCESSFUL"
   ```

3. **Logged in with 2 different accounts?**
   - Device A: sender@test.com
   - Device B: receiver@test.com

4. **Is app on Device B in background?**
   - Notifications show when app is NOT active
   - When app is open, messages appear in real-time in chat
