HOW IT WORKS:

When notification arrives at Device B:
┌─────────────────────────────────────────────────────────┐
│ 1. Extract: title="User A", body="Hello!", messageId=123 │
│                                                          │
│ 2. Create key: "User AHello!123"                         │
│                                                          │
│ 3. Check: Is this key in recentNotifications set?        │
│    ❌ NOT FOUND → New notification                      │
│    ✅ FOUND → Duplicate!                                │
│                                                          │
│ 4. If new:                                               │
│    ✅ Show notification                                 │
│    ✅ Add to recentNotifications set                     │
│                                                          │
│ 5. If duplicate:                                         │
│    ❌ IGNORE (silently drop)                            │
│    ❌ Don't show notification                            │
│                                                          │
│ 6. Cleanup: Keep only last 100 notifications             │
└─────────────────────────────────────────────────────────┘

RESULT: No matter how many times the notification is received,
        it only shows ONCE to the user! ✅
