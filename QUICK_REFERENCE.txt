## 🎓 Key Methods

### **Send Message with Media**
```kotlin
viewModel.sendMessage(
    roomId = "uid1_uid2",
    text = "Hello!",
    imageUrl = imageUrl,      // For image
    videoUrl = videoUrl       // For video
)
```

### **Edit Message**
```kotlin
viewModel.editMessage(
    roomName = "uid1_uid2",
    messageId = "msg123",
    newText = "Updated text"
)
```

### **Show Notification**
```kotlin
NotificationHelper.showMessageNotification(
    context,
    senderName = "John",
    messageText = "Hi!",
    mediaType = "image"  // or "video"
)
```

## 🛠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| No notifications | Check permissions: Settings → Notifications |
| Video doesn't upload | Check Firebase Storage rules |
| Edit button missing | Long-press (not tap), only your messages |
| Copy doesn't work | Check clipboard permission |
| Animation lag | Use real device, not emulator |
