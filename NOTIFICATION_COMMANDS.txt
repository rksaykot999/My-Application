====================================================================
                     TROUBLESHOOTING QUICK FIXES
====================================================================

❌ Problem: "Notifications not showing"
───────────────────────────────────────────────────────────────────
Solution 1: Check Permission
  Device Settings → Apps → YourApp → Permissions → Notifications → ON

Solution 2: Restart App
  Close app completely, open again

Solution 3: Restart Device
  Power off and on

Solution 4: Check FCM Token
  Firebase Console → Firestore → users → click your user ID
  Look for "fcmToken" field

❌ Problem: "Cloud Function error in logs"
───────────────────────────────────────────────────────────────────
Solution:
1. firebase deploy --only functions (redeploy)
2. Check internet connection
3. Check firebase CLI version: firebase --version

❌ Problem: "Build fails"
───────────────────────────────────────────────────────────────────
Solution:
1. File → Invalidate Caches → Restart
2. Build → Clean Project
3. Build → Make Project
